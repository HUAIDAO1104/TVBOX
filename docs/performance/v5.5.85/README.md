# v5.5.85 自动弹幕回归证据

2026-10-19。共用修复包括 AI 回复兼容、本地搜索回退、电视剧已解析集数保留、腾讯完整目录集号读取；没有按测试片名写分支。

- `unit-summary.json`：333 项单元测试通过。附协议、播放器标签及腾讯目录三组 XML。
- `protocol-before.log`：新增协议回归修复前 2 项失败；`drama-before.log`：平台明确集号回归修复前失败。
- `baseline.log`：v5.5.84 的 5 组电视剧自动 API 基线；`initial-mobile-matching.log`：后续扩大范围发现《庆余年第二季》14 集 NO_MATCH。二者均保留，不能用偶尔命中的备用接口掩盖直连漏集问题。
- `mobile-matching.log`：最终代码整轮 40 项，39 项首次通过，1 项公开播放器 AI 回退连接超时。重建 ADB 本机转发后同包复测，`mobile-extra.log` 的该项及 2 项客户端测试均通过；不是修改产品代码后隐去失败。
- `leanback-matching.log`：最终电视构建 42 项全通过，含相同的播放器自动入口和真实模型回退。
- `*-logcat.txt` 仅保留匹配、失败阶段、耗时和移动像素；`live-model-calls.jsonl` 保存本轮 29 条真实模型的脱敏结构化记录，包括排查阶段请求，不能全部计为最终用例数。真实 Key 只在本机临时转发进程内存中，测试后关闭；设备仅有测试占位凭据。
- 四张 `*-timeline.png` 为腾讯／芒果真实弹幕在专用静音长视频测试夹具中的画面，黑底为夹具。另有 1／10／40 分钟、暂停、全屏、后台恢复的移动像素检查。

使用 Android API 36 ARM64 Android TV 系统模拟器，分别安装 mobile 和 leanback 独立构建及对应分辨率；没有连接用户实体手机、电视。真实模型回复来自服务商 `deepseek-v4-1-flash-260910`。测速包含不同缓存状态，详情见根目录报告，不能承诺用户网络秒出。
